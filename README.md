# Solving Sudoku Puzzles with a Custom Genetic Algorithm

This project implements a custom genetic algorithm to solve (and create) sudoku puzzles. Each ansatz solution represents a complete Sudoku grid where the original clues remain fixed throughout the optimization process.

The algorithm evolves a population of ansatz solutions over multiple generations until either a valid Sudoku is found (weight = 0) or the maximum number of generations is reached.


## Algorithm Workflow

1. Load the Sudoku puzzle
    - Read the puzzle from a file.
    - Identify the fixed clues that cannot be modified during evolution.

2. Generate the initial population
    - Create an initial population of N candidate Sudoku filled puzzles.
    - Each candidate is generated by filling the empty cells while preserving the original clues.

3. Evolution loop

    a. Introduce random individuals: 

        Generate a small number of completely new Sudoku filled puzzles ("births from vacuum"). These individuals increase genetic diversity and help prevent premature convergence.

    b. Mutate existing population:

        Randomly select individuals from the population. 
        Apply mutation operations that modify only the non-fixed cells while keeping the original clues unchanged.

    c. Generate descendants:

        Produce offspring by combining information from existing candidate solutions.
        The crossover strategy attempts to inherit useful traits from the parents.

    d. Mutate descendants: 

        Apply a stronger mutation to the newly created offspring.
        This encourages exploration of new regions of the search space.

    e. Survival of the Fittest:

        Combine the current population and the offspring.
        Evaluate every candidate using the weight function.
        Keep only the best N individuals to form the next generation.

4. Check for convergence
    - Evaluate the best individual. If its weight is zero, a valid Sudoku solution has been found and the algorithm terminates. Otherwise, continue evolving until the generation limit is reached.


## Weight Function

The weight (or fitness) measures how far a candidate solution is from a valid Sudoku. A weight value of 0 indicates a correct solution satisfying all Sudoku constraints. Higher weight values correspond to larger numbers of constraint violations, such as repeated numbers within rows, columns, or subgrids. The genetic algorithm attempts to minimize this value over successive generations.
